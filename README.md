# Multimodal Emotion Recognition (MER) Pipeline
Designed for the IIITH Research Program Evaluation.

## 🚀 How To Run
1. Run `models/speech_pipeline/train.py` to evaluate speech features.
2. Run `models/text_pipeline/train.py` to evaluate text semantic features.
3. Run `models/fusion_pipeline/train.py` to perform Late Multimodal Fusion.

All accuracy tables and t-SNE visual separability plots are available inside the `/project/Results/` directory.
